There is a game with a similar spirit called Squirm:

http://homepages.di.fc.ul.pt/~jpn/gv/squirm.htm

It may be even more strategic than Kink, given that there is not a
fixed length for a winning string (or "snake" here) and that there can
be more than one bend in it. For some reason, the author established a
very small board for Squirm, which makes me thing that it may not work
as a serious, "full-sized" strategical game.

Anyway, yours is an interesting and original idea, which is a lot to
say for an N-in-a-row game. (And I love your Quoridor variant too!)
