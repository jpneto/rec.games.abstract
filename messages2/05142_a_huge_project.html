this is a xpost.
this is the first time i post, but i've been lurking for a little while.
since a few months ago, i began thinking about a possible challenging
project, which (if realized) would mean a big help for high school algebra
students, and a huge time-saver for math teachers too. also, it could
represent a challenge extending well beyond the stated objective, as it
might involve pattern recognition problems, strategic decision and so forth.
what i was thinking about was something like this:

+ a system for transforming/simplifying algebraic expressions, following
certain rules, such that not only it produces the simplest possible form
(according to some criteria) but also the various steps to reach it.
example:
(1-2*3)(-5-4)
(1-6)(-9)
(-5)(-9)
45
in this case it followed the operation/parenthesis hierarchy, but also:
(1-2*3)(-5-4)
-1*5-1*4+2*3*5+2*3*4
-5-4+30+24
-9+30+24
21+24
45
here the distributive rule was first used.
+ the user should be able to select a certain transformation strategy
(series of rules) from a (user-configurable) list, as to obtain two or more
different successions of steps as before.
+ the simplification sequence should be automatic as before or
alternatively the user should be able to interact with the sequence, follow
it step by step, even change the tranformation strategy halfway, or decide
to use different strategies in different subexpressions of the same
expression, by selecting such subexpressions in some interactive way.
+ it should be possible to "step back".
+ there should be a "drill mode", in which the user is given an exercise,
tries a step, gets a correction or a suggestion if he's wrong, gets a
continuous evaluation at each step and a final evaluation, according to
certain critera (decided by the user, in this case the teacher).
+ it should be possible to use different kinds of notations, e.g.
fractions in mixed mode as 7 1/2 which outside the anglophone world means
7+1/2; use fractions and/or decimals; use numbers and letters.
+ it should be possible to use a terminal-mode ascii rendering for
expressing fractions, powers, and so forth; or a graphical mode, e.g.
producing ps or html output.
+ is should consist of a stand-alone application, or a web client-server
architecture, such that teachers could simply say: "hey kids, as your
homework go to www.mypage.ourschool.org and click here and here and do the
#1, #2, #5 drills: you will get automatic suggestions, corrections and
evaluations; tomorrow we will discuss your work together in the computer
room at school." the pupils should only have access to a web browser, so
that there's no need to install the application in their home computer. the
pupil's work would be logged and later used for evaluations and personalised
correction work.
+ finally, but the most important, the system should be highly
configurable by the user: even if some day a martian pupil should meet a
venusian teacher, the program should make it possible (after some tinkering
with the configuration files) to have an educational relationship between
the two in minutes. here, we're talking about math or algebra, but it should
be possible to treat any sequence of symbols with a certain structure,
regardless of the possible interpretation (or better: the interpretation
should be completely expressed in certain configuration files, if it is
different from default algebraic meaning...)

am i only dreaming?

the meaning of this post is to get possible suggestions and/or criticism,
even name-calling is accepted ;) but please do not ignore it.

in particular: is such a job possible? has it partially or totally been done
already? what tool/language/environment would be better at it?

caution: if possible, give suggestions using only free software under a free
operating system (gnu/linux, *bsd, etc...)

thats all folks
