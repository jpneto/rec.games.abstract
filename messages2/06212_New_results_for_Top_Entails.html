New results for Top Entails

From: cet1@cus.cam.ac.uk (Chris Thompson)
Date: 17 Apr 2003 13:57:42 GMT

"Top Entails" was introduced in [1], pp 376-379, as an example of
a nim-like impartial game with entailing moves. It is played with
stacks of coins and the allowed moves are (1) to split one stack
into two non-empty stacks, or (2) to remove just one coin from one
stack, in which case the opponent is _entailed_ to reply with a move
(of either type) in the resulting stack. The game terminates when
a player creates a stack of size 0 (necessarily by a move of type 2)
and the next player loses because there is no legal move in such a
stack.

In such a game the Sprague-Grundy theory has to be extended so that
a stack of size N has a _set_ of G-values, all of which are relevant
if it is reached by an entailing move, but only the smallest if it
is reached by a non-entailing move. See [1] chapter 12 for details.
In particular the set can be empty, in which case the stack size
is said to be _loony_, as the position in which it occurs is
automatically a loss for the previous player regardless of which
sort of move it was reached by, and regardless of the sizes of any
other stacks.

In [1] the authors point out that 1 and 3 are loony stack sizes,
and ask whether there are any others. In [2a], Julian West describes
computations for stack sizes up to 600000, and the discovery of
three new loony values.

(On a personal note, I did similar computations, up to around 140000,
and found the same three loony values, at what must have been about
the same time. But I never got round to publishing them, so
I certainly don't deserve any credit for that.)

[2b] and [3a] (#11 in the list) describe no progress to date beyond
Julian West's results.

As a result of discussions between us in late 2002, David Seal did
some computations over the Christmas / New Year break, for stack
sizes up to 4000000. The values computed agree with those in [2a]
(and my own computations referred to above), but the new values
remain unconfirmed by independent calculation so far. The results
include four more loony values:

We would like to know of any other computations of values for
Top Entails, or if none have yet been performed we would like
to encourage others to confirm the above results.
