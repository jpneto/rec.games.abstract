Game: Fractured Toe

Here's one I invented when I was 15. It helped make my math class
bearable.

The goal of Fractured Toe is to place three symbols (x's or o's or
whatnot,) in a row, horizontally, vertically, or diagonally. Sound
familiar?

The initial board consists of a single segment connecting two adjacent
points on an infinite square grid. (In practice, it can be smaller than
infinite.)

Players alternate turns. A turn has two stages:

First: placing a symbol. One may place one's symbol only in an empty
square that is adjacent to a segment. For example, if the board is as
follows,

+-
|o

x may place eir symbol to the left of the o:

+-
x|o

Second: placing a segment. The segment must be an edge of a cell in the
grid that connects to a segment that has already been placed. Using the
example above, player x may place a segment as below:

+-
x|o
-+

Generally, the second part of the turn involves more strategy than the
first, as there are always many more legal moves. Often the symbol
placement is forced.
Whenever a player places a segment between two adjacent symbols (or
already available empty cells,) the number of moves available for symbol
placement is decreased. How should the case in which no legal moves for
symbol placement remain be resolved? The possibilities I see are:

1) It is illegal to place a segment such that no available cells for
symbol placement remain. This is the variant I have generally played.

2) If no available cells remain, a player must pass on the symbol
placement portion of the turn, but must still place a segment.

3) Each player has a counter which is incremented whenever e places a
segment that opens two cells, and is decremented whenever e places a
segment that opens no new cells. The counters are initially set to 0 and
may not become negative. I haven't tried this. Setting the second
player's counter initially to 1 might help offset the first player's
advantage while still guaranteeing that symbols can be placed.


Another problem is that, quite frequently, situations where both players
would (as below) have a threat to win in a square if the other player
first extended a segment there begin to crowd the board.


o|o
+-
|x
+
x|

The game seems too closed as it is without the restriction in laying
segments that this creates. Perhaps a solution would be to put a mark
between the square where the mutual threat lies and adjacent cells at
the time the second threat is created, with a rule that a row of 3
spanning this mark would not be a win.

o|o'
+-`
|x
+
x|

I've never had a chance to try this variant.

I suspect that optimal play would cause the game to be endless, (at
least with variant 1 above) but proving that might be difficult.
