Ever wonder what software everyone uses to post to USENET?

It's Mailloop v3.1...

Why? Because it's powerful and easy to use - all you have to do is:

1) Create a message (http://www.mailloop.com/editor.html)
.....by using the pull down menus or
.....by using any editor
2) Create a custom newsgroups list
.....by filtering an NNTP server (http://www.mailloop.com/filter.html) or
.....by importing from any text file (http://www.mailloop.com/importng.html) or
.....by manually creating with any editor or
.....by extracting from any FTP downloaded file (http://www.mailloop.com/ftp.html) or
.....by extracting from any HTTP (http://www.mailloop.com/http.html) downloaded file
3) Create a custom e-mail list
.....by extracting from newsgroups (http://www.mailloop.com/extract.html) or
.....by importing from any text file (http://www.mailloop.com/importem.html) or
.....by manually creating with any editor or
.....by extracting from a WHOIS response (http://www.mailloop.com/whois.html) or
.....by extracting from a fingering response (http://www.mailloop.com/finger.html) or
.....by extracting from a UNIX command response (http://www.mailloop.com/exec.html) or
.....by extracting from any FTP downloaded file (http://www.mailloop.com/ftp.html) or
.....by extracting from any HTTP downloaded file (http://www.mailloop.com/http.html) or
.....by using the newsletter server (http://www.mailloop.com/nlserver.html)
4) Broadcast the message to the e-mail list
.....by selecting the e-mail broadcast option (http://www.mailloop.com/embc.html) or
.....by using the newsletter server (http://www.mailloop.com/running.html)
5) Broadcast the message by selecting the newsgroup broadcast option (http://www.mailloop.com/ngbc.html)
6) Then process the remove requests (http://www.mailloop.com/eexclude.html)
.....by using the incoming mailbox processor (http://www.mailloop.com/pop.html)

See http://www.mailloop.com for more info.
