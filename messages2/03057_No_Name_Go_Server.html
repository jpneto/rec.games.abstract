NNGS

The No-Name Go Server


We have affectionately named it "NNGS" or "No Name Go Server", hoping
that the right name will come to us at some time. NNGS has been
carefully designed so that the client programmers will not have to
change their programs, so it will be mostly compatible with your
favorite client.

Some notable items at NNGS:

1) Pair Go (RenGo). This is (and has been) fully operational. See "help
pair-go".

2) Many new commands such as awho, censor, and gshout (Go related
shout).

3) Currently, no rating system exists. We are working hard at
designing one, and are constantly collecting data and ideas.
Please feel free to give us your input!

4) We do have a great Ladder System, which is a continuously running
tournament for serious players. By winning just one even game,
the challenger replaces the opponent's place on the ladder.

5) Source code availability. I am a strong believer in the GNU
project. Once the server is stable (should not be too long), we
will make the entire source code available for anonymous ftp.

6) Many friends who will respond to your ideas and questions.
