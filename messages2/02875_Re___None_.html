there is no solution. the problem can be transformed into a "islands
and bridges problem" (of the "Bridges of Koenigsburg" type). it is a
theorem of graph theory that a network has an Euler path (a path which
traverses each edge exactly once) if and only if the network has at
most two vertices of odd degree. the equivalent network for this
problem has six vertices (one for each "room" plus one for the
exterior) and 16 edges. the degrees of the six vertices are 4, 5, 5,
7, 5, and 4; obviously, more than two of these are odd.

the proof of the theorem is not complicated. an Euler path can have
only one beginning and one ending. however, a vertex with odd degree
must be either the beginning or the end of an Euler path. therefore,
a network with more than two vertices of odd degree cannot have a
Euler path (as this would engender a contradiction). the formal proof
is left as an exercise to the reader.
