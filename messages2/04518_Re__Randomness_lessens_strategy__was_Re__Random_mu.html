> Hogwash. Randomness simply forces you to adopt strategies that take

Has there been some research on how random events influence
decision complexity of strategy?

My intuitive guess would be that uniform random events that
replace decisions decrease the strategic complexity. E.g.
consider a binary decision tree with only one path to a
best leaf. In game S at every node the player makes the
decision strategically. In game R the uniform random event
generator (coin) makes the decision instead. Game S has a
complexity 2 to the power tree depth, game R has a constant
complexity for the player. What about game R2 where the
random generator only acts at odd tree levels? The complexity
should be roughly 2 to the power half the tree depth then.
Or am I misunderstanding probabilistic behaviour entirely?
