Dr. Bronia Grycz <destiny@gmtnet.co.uk> wrote:

In a nutshell, a *perfect* board game ought to:

A3: have simple, clear and elegant rules with minimal exceptions (O)
A4: have elegant strategy, preferably not traceable by a computer (O)

My definition of the "perfect" game would be one whose rules are "simple,
clear and elegant", yet whose strategy is "deep". Tic-tac-toe satisfies
A3, but provides little depth of play, although A4 qualifies this.

As I've mentioned before in rec.games.design, I like to classify games
with respect to their complexity of rules and depth of strategy. Each
game can be described as a rectangle, thusly:

Tic Badly
Go/ Tac Typical Designed Family
Chess Toe Wargame Wargame! Game
+---+ +---+ +---------+ +--------+ +----+
| | | | | | | | | |
| | +---+ | | +--------+ | |
| | | | +----+
| | | |
| | +---------+
| |
+---+

The width of the rectangle describes the complexity of the rules. Go,
chess, and tic-tac-toe have very simple and elegant rule-sets. Wargames
have much more complicated rule-sets, so their rectangles are wider. The
height (or depth) of the rectangle indicates the depth of strategy of the
game. Go and chess manage to achieve very deep strategies despite their
small rule-sets. Wargames tend to achieve relatively deep strategies only
because of their large rule-sets. Most family games have some slight
strategy, and tic-tac-toe's strategy is trivial.

Note that, although I imply that both chess and go would be "perfect"
games, I prefer games whose rule-sets are greater and whose strategy isn't
quite as deep (closer to family games). I game primarily for social
reasons, and highly strategic competition seems to squelch any social
interaction.
