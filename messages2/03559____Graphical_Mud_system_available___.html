GRAPHICAL client/server system
--

For anyone who's interested, I recently took the trouble to write a
graphical client/server system which can be bolted onto most muds.
It displays 8-24 bit colour images (JPEGs), which can be attached to any
items within the game - be they locations, objects or players, whatever.

Currently it runs under X Windows and UNIX, and I am in the process of
developing a Windows 95 client. The current prototypical version is not
commercial, and is freely-available, although commercial arrangements
can probably be made for interested parties.

I am quite keen to see how it works out in the real world, but not
having a mud site of my own this makes it a little difficult, so if
you run a mud and would like more information, please email me at
creech@tardis.ed.ac.uk
