Mark's "Crossway" is similar, prohibiting the a 2x2 checkered pattern to be
completed. I don't like the rule because it is supposedly just a way to mark
the connections, but it is possible to be in a position in which an extra
piece hurts you rather than helps you:

"O" to play, "O" wins by playing at "*"
+---+---+---+---+
| o | | | |
+---+---+---+---+
| o | x | | |
+---+---+---+---+
| | * | x | x |
+---+---+---+---+
| x | | o | o |
+---+---+---+---+

"O" has an extra stone at (o) and loses!
+---+---+---+---+
| o | | | |
+---+---+---+---+
| o | x |(o)| |
+---+---+---+---+
| | | x | x |
+---+---+---+---+
| x | | o | o |
