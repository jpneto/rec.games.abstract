jpn@di.fc.ul.pt (Joo Pedro Neto) wrote

> I invented a Hex variant, called Nex with the following rules:

I suggested calling it "Neux", to emphasize the neutral-stone aspect,
and also so that it sounds like "Nukes", which seems appropriate
considering the effect some unexpected moves have!

> The game is really interesting and I advise people who like
> connection games to give it a try.

It is indeed utterly fascinating. Interestingly, as the total number
of stones on the board for each player still only goes up as one per turn,
the games do not tend to be noticeably longer than the standard forms;
but the scope for skill and trickery is much greater.

Also, the games can be "cleaner", as stones that have become virtually
useless can be recycled by turning them neutral.

It is a wonderful mutator!

> Anyway, this idea (drop a 1 friend + 1 neutral OR flip 1 friend + 2
> neutrals) can be extended to many different games. I think that games
> where each move is a drop are excellent targets like Go, Gomoku or Hex.

All the connection games are of this type OC; such as Y, Jade, Projex, Unlur,
Quax and so forth. All three that we are trying, Neux, NeuGo, NeuGomoku,
have unexpected intricacies. With NeuGo one must also decide how stones
are to be captured - whether or not neutrals can assist in a capture.
We have decided (for now) that they do NOT - neutrals act as liberties
for both colours.

Anyway, as Joao said, everyone is earnestly enjoined to give them a go.

Hell - who knows...
- maybe even TicTacToe will be interesting with this new mutator!! :)
