In germany exist a game called "Das Spiel". It is a triangular Board
with hundreds of colored dices (d6). You can build a pyramid with the
dices on the board. There exists many rules for many games with this set
of pieces. In some games you need a good taktik in others only luck or
dexterity or a combination of this skills.
