Predators is a free open-ended pbem game. The game is a very abstract
simulation of species evolution. It's a variant of the game Food Chain.

Players send orders to the email server to design new species in the jungle,
by creation or mutation. The objective of the player is to obtain the
maximum of species in the jungle by successive mutations.

Players may enter the game at any time, there is no limit to the number of
game turns. Currently, the game has run 50 turns, there is 44 species in the
jungle.

A cycle of the game is processed every 24 hours. In this game turn, each
individual animal of any species get a chance to eat another one, to be eaten,
or to die of starvation. Successful species have a growth of their population,
unsuccessful decline and disappear.

The game status is updated by the players orders several times per day, but
the responses to the orders are not immediately mailed (modem connection).

To get the current game status, send a mail to : preda@altavista.net with
the word "report" in the body of the message or "rules" ... to get the rules.

Short description and rules can be found at :
http://www.capway.com/dumonte1/predators.html

By default, the game language is set to "english", but you can set it to
"french".
