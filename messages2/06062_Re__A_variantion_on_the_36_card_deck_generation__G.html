true d7. I didn't count this, as I considered only polyhedrons that
can rest on all faces, which dice need not necessarily be. You could,
for example make a d7 as a 7-sided pyramid with a rounded base, so the
die can't rest on this. This has the same problem of having an edge
on top, but you could put the numbers on the base. This makes it
essentialy a tee-totum. Still, I would prefer a d14 as described
above.
