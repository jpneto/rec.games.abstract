*two player game
*Objective of game: annihilation of every single living part of
opponent
*The construction of the game characters will be the following:
Each player will be able to design their character of choice from the
four elements, which you will read later about.
For all the other "breeding" characters they will be randomly
designed using the binary generator.
Each of the player's characters in the game will have these four
elements, a certain amount of life, a certain amount of attack, a
certain amount of speed, and a certain amount of teach ( teach is
important because it is a variable that increases of decrease on the
level that the two players battle.)
The breeders only have three elements.
The breeding characters play no part in the various game levels except
to passively mate with the two player's characters.
The breeding characters are essential to the game because they cause
mutations in the player's original character design that may be
beneficial in the later stages of the game, also, they multiply the
certain amounts of the elements by 2X, 3X or add or subtract counters,
minus 3 life counters or add 1 speed counter, etc., e.g., in the first
stage, the two players opt to have their characters "max-out" with all
of the certain amounts of life, attack, speed, and teach from the
alpha pool; for instance, each player's character A and B has a max 20
life, max 1+attack, max 2+speed, and max 5+teach to choose from; so in
other words, both of the players characters elements will be equal;
the breeders are not designed with such intentions or equality but
designed randomly; so some breeders might have minus 5 life, others
might have 0+ attack, and, yet, others might have add 4 speed, and,
even yet, some might even have multiply life by 3.

Each of those elements in the characters will be represented by a
binary code and used in a way to form the new characters, e.g.,
2x2x2x2x2x2=64, the number 0-9 will be represent, by coin, as
1=HTHTHT, 2=THTHTH, and so forth; the operators, such as
multiplication and stuff, that only the breeder posses will be
represented by, add=HHHTTT, subtract=TTTHHH, and Multiply=HHHHHH.
To make it a little more plain, player's character A code is:
{HHHHHT [life] HTHTHT THTHTH [20],}
{TTTTHH [attack] TTHTTH [plus] HTHTHT [1],}
{TTTHTH [speed] TTHTTH [plus] THTHTH [2],}
{THTHHT [teach] TTTHHT [5].}
Now the breeders are randomly designed using coins, probability, duh.
If you have elementary mathematic you will know the rest. One thing
the breeders do not posses is code for teaching.
Breeder, A1473
{HHHHHT [life] TTTHHH [subtract] THTHTH [2],}
{TTTTHH [attack] HTHTTH [add] THTHTH [2],}
{TTTHTH [speed] HTHTTH [add] HTHTHT [1].}
Now take players character A and breeder A1473, do a little simple
arithmetic and, presto, you have a new character ready to go on to the
next level.

New character from the player's character A and A1474
{HHHHHT [life] *save time* [18],}
{TTTTHH [attack] [3],}
{TTTHTH [speed] [3],}
{THTHHT [teach] [X].}
You notice the X in the code of teach, the value is not yet decided.
After the game of the level is completed and the wins and loses are
translated into teach counters then can the value be known.
*The element teach is really for a higher idea of this simple core
game, the player's character can only pass that trait on to one
creature that then will be used to boost the life, fighting and speed
elements on that chosen new character. So it is to the player's
advantage if he breeds with as many random generated breeders in each
level. The player will have a wider selection to choose from and pass
the teaching element forward to the chosen one.
Some other thoughts before this place closes.
*Mind that the breeders will have a wide range of values.
*The game levels can have a randomly number of breeders, but the
player's character can only mate with a breeder once, meaning the
opponent can not breed with that same breeder. At the end of the time
limit or stage, the players view all the elements of all the creatures
it mated with and selects one to continue into the next stages, which
will be constructed in a way that either boosts or diminishes the new
characters traits.
*The games that decide the teaching plus or minus points can easily be
constructed in smaller games found in the large game construct. Yes,

the larger game construct to decide teaching points. Shit, if you have
