Greetings. I recently sent an email to someone who was asking for information
about any board game which uses "undifferentiated pieces," such as checkers.
AFTER deleting his email address from my files (of course), I discover that
I left out the crucial word "diagonally" from the rules I sent. So, hey out
there! Here are the correct rules to this game. Hopefully, some other folks
will find this interesting as well.

THE MEDITATION GAME

was invented by Layman Allen, inventor of "WFF'N'PROOF" and "Equations."
If you order from

WFF'N'PROOF PUBLISHERS
1490 South Boulevard
Ann Arbor, Michigan 48104-4699
USA

(313) 665-2269

then you'll probably receive this game as a free bonus, if it's in stock.
I don't know if they actually SELL it.

Here's what the board looks like:

----------------------
|O |O | | | |G |G |
----------------------
| |O |O | |G |G | |
----------------------
| | |O | |G | | |
----------------------
| | | |* | | | |
----------------------
| | |G | |O | | |
----------------------
| |G |G | |O |O | |
----------------------
|G |G | | | |O |O |
----------------------

It's a 7x7 grid of squares. O means orange square, G means green square,
and * indicates the central "star" square. The tokens are these little
plastic rings, all the same color. Mine are blue. It's a 2-player game;
players alternate moves. The board is empty of tokens at the start.
The first move is to place a token on any of the 8 squares adjacent to the
central * square. After that, each move consists of placing a token on any
vacant square adjacent to the last played token, horizontally, DIAGONALLY, or
vertically. One player is designated Orange; the other is Green. Play
continues until either: all of one player's squares are occupied, or: there
is no legal move available because all of the squares adjacent to the last
played token are occupied. Your score= the number of squares of your color
which are occupied. The * square has no effect on the score. High score wins.
Equal score is a tie.
