Just another note: for maximum speed, you should retain certain data
between moves. For example, if a counter is added, and none
disappear, then it may form a new group, add to a group, or join
some groups. Something to think about if you are going to make your
program as strong as possible.

But implement the simple version first - you can replace your
'group-analyser' code by something more efficient later on.
