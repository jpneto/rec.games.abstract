Now I am going to name states more fully. Each state in the game will
be identified by a 2 digit number. The first digit is the number of
rolls remaining and the second digit is the largest number of matching
dice (the numbering used in the state transitions calculated above).
So that 30 is the initial state and 01, 02, 03, 04 and 05 are the terminal
states.
The value of states will be denoted as [xx].

Now we give values to the terminal states:
[05] (a yahtzee) = 1.
[01], [02], [03] and [04] (not yahtzees) 0.

Now we start back tracking.
[15] = [05] = 1.
[14] = [04]*5/6 + [05]*1/6 = 1/6.
[13] = [03]*25/6^2 + [04]*10/6^2 + [05]*1/6^2 = 1/6^2.
[12] = [02]*20/6^2 + [03]*80/6^3 + [04]*15/6^3 + [05]*1/6^3 = 1/6^3.
[11] = [01]*20/6^3 + [02]*25/6^2 + [03]*250/6^4 + [04]*25/6^4 + [05]*1/6^4
= 1/6^4.
[25] = [15] = 1.
[24] = [14]*5/6 + [15]*1/6
= 5/6^2 + 1/6 = 11/6^2.
[23] = [13]*25/6^2 + [14]*10/6^2 + [15]*1/6^2
= 25/6^4 + 10/6^3 + 1/6^2 = 121/6^4.
[22] = [12]*20/6^2 + [13]*80/6^3 + [14]*15/6^3 + [15]*1/6^3
= 20/6^5 + 80/6^5 + 15/6^4 + 1/6^3 = 226/6^5.
[21] = [11]*20/6^3 + [12]*25/6^2 + [13]*250/6^4 + [14]*25/6^4 + [15]*1/6^4
= 20/6^7 + 25/6^5 + 250/6^6 + 25/6^5 + 1/6^4 = 3536/6^7.
[30] = [21]*20/6^3 + [22]*25/6^2 + [23]*250/6^4 + [24]*25/6^4 + [25]*1/6^4
= 70720/6^10 + 5650/6^7 + 30250/6^8 + 275/6^6 + 1/6^4
= 2783176/6^10 = 2783176/60466176 = 347897/7558272

So, barring any mistakes in my math, there is a 347897/7558272 chance of
getting a yahtzee using up to three rolls with best play.

The above calculation is a pain to do by hand, but is hardly complicated
to do by computer. Note to actually figure out what strategy you should
use, the back tracking is a little more complicated. At any decision point
you have to evaluate the value of each possible decision and then pick the
best one.

The hard part of game analysis is trying to do something when a brute force
solution isn't feasible. This may involve trying to reduce the number of
states somehow or trying to get approximate solutions.
