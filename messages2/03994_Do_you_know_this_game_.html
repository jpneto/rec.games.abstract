Once I had read an article about a *very* abstract game. I don't remember the
author, but I think it was either Martin Gardner or Douglas Hofstadter
in Scientific American columns.

The game needed no components except paper and pencils and any number of
players (greater than two) could play the game. The game had a most
interesting property that ALL of its rules was subject to change! There
were a number of initial law-like rules that declared how the game was
played in turns, who would win and most importantly how the rules can be
changed. (Basically with some kind of voting system) The really nice thing is,
of course, all of these rules can change through the initial mechanism
provided. The players could add new rules, change existing ones, delete rules,
etc. With each change the game would become a new game. (Can I say a new game?
Or is it the same game with different rules? But if rules are so different
how can two be the same? Oh well...)

If I don't remember it wrong, it was even possible to convert the game into
any other existing game by changing the rules. It wasn't something easy to
do, but it was theoratically possible to change most of the rules to have
the effect: 'We'll play ... now, and the winner of that game will be the
winner of this game'

If you have heard of this game, or have the initial rules, or can help me to
find them, I'd appreciate it.
