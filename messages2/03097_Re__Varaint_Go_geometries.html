I have once suggested using Penrose tiles for Go.

Penrose tiles exist in different variants. I'm considering the version
where the tiles are two different rhombes. The interesting property of
Penrose tiles is that you can make arbitrary sized (even infinite)
tilings of the plane, but no tiling can be periodic. Each tile has
four neighbours, so the number of liberties is the same as for the
standard Go game. But the way to construct safe groups depends on how
the tiles are connected, which is different for every tile on the
board! (Actually, small local patterns often re-occur at several
places on the board).

The game would be played in two phases: board lay-out and stone
placement. The stone placement would be played using the standard Go
rules. The board lay-out consists of setting up a board. The players
alternate placing tiles on the table. To avoid holes (as much as
possible), players are rewarded by the number of other tiles their
newly placed tile touches. This can be done by capturing a number of
enemy stones equal to the number of touching tiles (or liberating the
same amount of stones from the opponent). Since the first player is
obviously at a disadvantage here, I suggest letting the first player
also play last. Any size of board can be constructed, but I think the
game would be too complex if more than 100 tiles are used. 60 is
probably enough. Note that it is possible to make boards with holes
that cannot be filled using the restrictions of Penrose tiles. Such
holes will act like small local 'edges'.

Literature on Penrose tiles include Martin Gardners "Penrose tiles to
trapdoor cyphers" and Roger Penroses own "The emperors new mind".
