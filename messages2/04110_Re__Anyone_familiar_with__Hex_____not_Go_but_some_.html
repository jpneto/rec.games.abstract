> The argument "an extra piece anywhere on the board cannot hurt you" is
> basically a proof that it cannot be a second player win. To see it
> precisely, suppose the second player (O) had a winning strategy. The
> first player (X) starts out with some arbitrary move on square s. But in
his
> mind, he pretends to be playing another imaginary Hex game, which is
> rotated 90 degrees from the actual Hex game, in which (rotated) square s
is
> still empty. In this imaginary game, X is the second player. The
> imaginary game is identical to the actual game except that X has one fewer
> piece on the board, and he is playing second instead of first. Note that
> the fact that the Hex board is "square" is important here. From this
> point on, X makes his moves by first determining where he would move in
> the imaginary game, and then making the corresponding move in the actual
game.
>
> The only problem with this is if in the imaginary game, he is required to
> respond on square s. He can't do this in the real game, since square s
> was filled by X's first move. But it doesn't matter. In the actual game,
> he makes any random response on any empty square s' while still responding
> on s in the imaginary game. This doesn't affect the situation because the
> actual game still differs from the imaginary game by one square in which X
> has an extra piece, though this square is now s' instead of s.
>
> However, the point is that because X is playing as the second player in
> the imaginary game, then (by assumption) X can win the imaginary game.
> When X wins the imaginary game, then he has also won the actual game
because
> the rotation by 90 degrees makes winning configurations correspond
> in the 2 games, and the extra X piece in the actual game cannot destroy a
> winning configuration. O could not have won earlier in the actual game,
> since that would mean that O won earlier in the imaginary game also.
>
> This is a contradiction, since X, as the first player in the actual game,
> was not supposed to be able to win it.
>
> Therefore, the second player has no winning strategy in Hex. Either the
> first player has a strategy, or the game is a draw. We can prove that a
> draw is impossible (which I won't do right now), so the first player has a
> winning strategy. This proof has not told us anything about how X can
win.
>
> Note that this proof applies to _any_ 2 player game in which:
> 1) Players take turns marking one square per turn from a set of 'squares'
> S (which can be arranged in any way) with their symbol (X or O);
> 2) There are 2 sets of subsets of squares, W_1 and W_2, such that:
> a) player i wins if and only if he marks all the squares in some
> element of W_i first.
> b) There is a permutation of S, carrying W_1 bijectively to W_2.
>
> This applies to Hex, tic-tac-toe, k-in-a-row (for any k, on any size
> or shape board, in any number of dimensions), etc. In all these games,
> either the first player has a winning strategy, or the game is drawn with
> optimal play. Note that we do not need to assume that the number of
> squares is finite nor does it matter if we allow X and O to both take the
> same square (although games without the latter constraint are not very
> interesting :)
