After each move, the turn is immediately advanced and an end of game
check is performed
(in this case, the check includes seeing if an enemy piece occupies
the former queen position).
If that occurs, the game is ended. Also, when there are no moves
available to a player, the
game concludes after generating moves for that player and not finding
any.
