Well, there are several reasons for this. Allow me to detail a few:

1) We will not always be using IGS compatible clients. This is simply a
first step of many first steps we plan to take with Go on the Internet.

2) The current port that is being used (6969) has caused many problems for
quite a few people because some site administrators block access to it,
claiming it as either a mud or IRC server port (IRC normally uses 6667, 6666,
6668, and I have seen 6669). This is why there is a port 7777 on IGS, (At
least, this is what I have been told as the reason for the 7777 port).

So, If there is a problem with the first choice, I felt that it would not be
too much of a hassle to have people change both the address and the port in
their configurations to make it here.

Yes, this does tend to go against the "standard". I feel times have changed,
and it is time to change with them.
