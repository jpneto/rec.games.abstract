Generally, though not always (Nim being a notable exception), the
larger a game tree is, the more resistant it is to first move
advantage. In order to be perfectly free, in a theoretical sense, of
first (or second) move advantage, the game would have to be infinitely
long, and therefore not a game. Realistically, to thwart first move
advantage in a practical sense, the game would have to be really,
really long. First move advantage doesn't normally kick in until
players start becoming rather expert. (Hex is an exception. Beginners
can feel the first move advantage right away.) Ideally a game should
be scalable, so beginners to have to suffer an extraordinarily lengthy
game, and experts can increase the size to accommodate their growing
skill.

As far as breaking up the game into multi-move turns, I don't like that
idea. You're effectively increasing the granularity, or decreasing the
total number of moves, making it even more vulnerable to first move
advantage - the very thing you're trying to avoid.
