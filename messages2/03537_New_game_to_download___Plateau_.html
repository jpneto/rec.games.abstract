There is now a computer program for the new abstract strategy game
called Plateau. It is on the web at:

http://iquest.com/~jwalbea/plateau.shtml

It runs on Windows95 and is being distributed as freeware. It has been
fairly extensively tested but I would like to see it pounded more before
I upload it to the major game sites. Send any comments or questions to
the address below.

The program allows you to play the computer or play a human opponent via
email. It also has an extensive help system with lots of animated
examples.
