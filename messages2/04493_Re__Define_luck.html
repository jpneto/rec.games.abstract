>Some proposed definitions.
>
>A game of no luck...
>
>1. is any abstract game of strategy with perfect information (which
>qualifies chess, go..., but not jenga, backgammon... i prefer this
>definition, although it is in one sense a mis-use of the word luck)

Why should a game of no luck be abstract?

I don't know whether luck plays a part in football; but if it does not,
then I think football should qualify as a game of no luck.

>2. is any game where no player may at any point get any advantage from any
>"best" decision that is made (this is tricky since it is hardly true for any
>games, but some seem to like to use this definition to qualify Diplomacy,
>although it fits description 3 better, and also this is not really true in
>Diplomacy.)

I cannot understand this.

>3. is any game where no player will get an advantage over the others to win
>at any point (like simultanous move chess or any standard abstract game by
>definition 1, where each player gets one game with each side.)

Nor this.

>4. is any game that can be reproduced by thought, and does not require any
>physical components (of course players can simulate dice rolls too, so this
>could possibly include chess, go, backgammon, monopoly..., although most
>would construct the definitions so that any games with dice or cards can not
>be reproduced).

>5. is any game with "abstract" components, components without a theme (like
>Jenga, backgammon, chess(maybe), checkers... but excluding Monopoly and
>Diplomacy)

What has theme got to do with it? We are defining "games of no luck".

Monopoly clearly involves luck, it uses dice. Diplomacy involves luck
if played at all competently, as the players use mixed strategies. The
"landlord" and "war" themes are irrelevant.
