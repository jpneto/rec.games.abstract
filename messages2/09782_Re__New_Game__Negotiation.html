A game with 42 triple moves does not have a broader game tree than a
game with 127 single moves. If you color the game tree in two colors
for the two players, all that happens is that you have a different
coloring, but not a different shaped tree, if this makes sense. And
the game with triple moves possibly pays a clarity penalty since a
player might have too much to consider in order to practically plan
his new few plays. But I am not trying to criticize the game itself;
I like the idea of Ecalper. I don't like games that are named with
backwards-spelled common words, though. I would prefer to see a
different name.
