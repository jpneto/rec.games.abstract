Fool <fool@kvackit.org> writes:

>Here is an operator inspired by the game of Diplomacy.

>The "simultaneity" operator maps "G", a 2-player, perfect knowledge game
>to "Sim(G)", a 2-player, imperfect knowledge game.

>Both players write down legal moves for the current state in G.
>Both players reveal their moves to each other.
>If both moves "commute" (the state in G is the same no matter which
>way the moves are executed), then the moves proceed. If one ordering
>of moves is illegal, then the moves proceed in the legal order. If
>both move orderings are illegal, or if the moves do not commute,
>there is a standoff, the state in G is unchanged (but not the state in
>Sim(G)) and both players have to write down _different_ moves for the
>current state in G.

>Generalization to N players:

>A direct generalization is possible such that if all the legal orderings
>of moves result in the same state, the moves proceed, otherwise there
>is a standoff. However it is desirable to have it such that if only
>a subset of players' moves interfere, then only those moves should
>fail, and the non-interfering (commutative) moves should succeed, and
>in this case there is no need to forbid the players from repeating the
>same move (as the state in G has changed).
>(E.g. in 3-player Chinese checkers, if two players try to move to the
>same space but the third makes a move on another part of the board,
>then the third player's move proceeds but the first two fail).

This generalization has the problem that there may be several ways to
remove moves such that there is no stand-off. In the Chinese checkers
example, removing any one of the two conflicting moves will make the
rest commute, but there is no fair way to choose which should be
removed.

This problem can be solved at the cost of a little complexity: We can
(partially) order sets of moves by subset. We can then look at the set
C of all commuting subsets of the original set of moves. Some of these
will be maximal, i.e., no other set in C is larger than this. There
may be several different maximal subsets (as in the example).

If there is a unique maximal commuting subset, this is the obvious
choice for the move in Sim(G). Otherwise, we choose the intersection
of all maximal subsets. In the example, this implies removing both the
moves that conflict. If we ignore support and convoys in Diplomacy,
this will yield the same results as the usual interpretation.

Since the intersection of a single set is the set itself, we can sum
this up as: We choose the intersection of all maximal commuting
subsets of the original move.

Note that there is a chance that the intersection is empty and hence
no move is made. Your suggestion is to forbid repeated moves in such
situations, but this may be a problem if all players have only one
legal non-empty move each, as this will force all to make empty moves
which will again result in a repeated position and hence a stuck
game. A possible solution is to put no restrictions on the next move
but say that if the situation doesn't change in two consecutive moves,
any player can declare the game a draw. If a player is clearly
leading, he will try an alternative (suboptimal) move in order to
avoid a draw. To avoid cycling between two different states (by moving
an unessential piece), the rule may have to be generalized to say that
if the same state occurs a total of three times or more, any player
can declare a draw.
