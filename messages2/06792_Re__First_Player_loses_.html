great mechanics. Figuring out where Nim comes in is part of the fun.

> > This is just the Misere form of Nim.
> >
> > In the normal form, the person who takes the last item *wins*.
> > To find a winning move, write down the number of items in
> > each row in binary. E.g. the starting position is
> >
> > 3 = 0 1 1
> > 4 = 1 0 0
> > 5 = 1 0 1
> >
> > You want to move to a position such that each column in the
> > binary representation contains an even number of 1s. There is
> > only one move to accomplish this, namely take two items from
> > the row with three in it achieving.
> >
> > 3 = 0 0 1
> > 4 = 1 0 0
> > 5 = 1 0 1
> >
> > By following this strategy for every move, the first player
> > will win. The strategy for the misere form is exactly the same
> > except for the move that reduces the last row with more than one
> > item in it to either zero or 1 item. In this case, if the winning
> > nim move is to take the entire row, then take all but 1 and if
> > the winning nim move is to take all but one, then take the entire
> > row.
