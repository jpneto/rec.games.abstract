I recently picked up a 1960 copy of the Parker Bros. game Kimbo. The rules I
have with the game are a little ambiguous:
1. Can you jump over friendly or enemy pieces when moving?
-- We have assumed, yes.
2. Can you land on a square containing a friendly piece?
-- We have assumed, no this is prohibited.
3. Do the start spaces count as one big square or four smaller squares?
-- We have assumed, yes, they're one big square.
4. The edge of the board isn't a "solid black line," but is it counted as
such?
-- We have assumed, yes, pieces are deflected from the edge as if it
were a solid black line or fence.

If anyone has another version of the rules that clarify these points, or if
anyone has any strong recommendations, please let me know.
