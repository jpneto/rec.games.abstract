Unfortunately, there is a major bug in your program.

> vlong C( vlong n, vlong m )
> {
> vlong result = 1;
> while ( m > 0 )
> {
> result = result * m;
> m -= 1;
> }
> return result;
> }

I guess this is meant to return the number of ways you can arrange m coins
on n squares. However, it is actually returning factorial(m), and ignoring
n completely !

Try replacing it with :

vlong Fact( vlong m )
{
vlong result = 1;
while ( m > 0 )
{
result = result * m;
m -= 1;
}
return result;
}

vlong C( vlong n, vlong m )
{
return Fact(n) / Fact(m) / Fact(n-m);
}

Also, the formula :

> C(62-n-wpiece,bpiece) * pow2(2*bpiece);

is returning numbers that are too big, as it does not allow for the fact
that if you have two rooks, you can swap them with each other without
changing the position. Same for all the other pieces too.
