Take the Plateau Challenge and get a game set for half price! If you
can beat the computer version of Plateau, a new abstract strategy board
game, then we will send you a real set for half price.

Plateau normally sells for $20.00, but send us a game record in which
you have beaten the computer and we will send you a set for only
$10.00. It's easy to record a Plateau game, just click "Save Game"
under the "File" menu.
