Senator: Request for Co-Implementor

From: richard@genome.wi.mit.edu (Richard Resnick)
Date: 16 Aug 1994 19:36:22 GMT

Greetings friends:

A few years back, I ran a game called Senator. It was very similar to
another game which goes by the name of Nomic. The rules are simple --
there are none. The players CREATE the game as they go along, by
proposing new rules and voting on them.

The game was a moderate success, until I as implementor had to quit --
I was running out of time to do the things that I _needed_ to get
done.

With more time on my hands, I am in the process of restarting the
game. This time, however, things will be different.

Where before all correspondence was via email, this game will be based
from an internet server. All players will have to be able to telnet to
the server, and from there, they can perform all the functions
required as part of the game.

I am currently coding the server. It will be ready for mass-usage in
about 1 month. Until then, I need a number of things:

o A co-implementor. This person will work with me to make sure
that the game and the server run smoothly. Requirements:
Knowledge of Perl, good taste, a sense of justice and a good
sense of humor.

o A machine to run the server on. Currently, I can run the server
on my machine, but only after normal working hours, and even
then, with some resistance. A secure site to run the server is a
necessity. Requirements: A person who has CLEAR permission to
run the server on their machine. A machine which has Perl
installed on it.

o Testers. As the server develops (but before the game starts), I
will need a few people who can connect to the server and try as
hard as possible to crash it. Requirements: 30 minutes a day. A
machine which can connect to hosts via telnet. Previous testing
experience would be nice.

o Players. I'd like a maximum of 50 players, but less is
fine. Requirements: The need to see things to their end. The
ability to debate. A machine which can connect to hosts via
telnet. Thirty minutes to an hour a day. An excellent sense of
humor. An excellent imagination.

You can reach me at: richard@genome.wi.mit.edu. I'd love to hear from
anybody who is interested in any of the above, and who fits the
requirements.

Senator is starting up, once again!

Richard Resnick
