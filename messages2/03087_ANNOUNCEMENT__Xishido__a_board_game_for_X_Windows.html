The PFF Software Group is proud to present Xishido!

Xishido is a board game for X Windows, played by one player. Following very
simple rules you must place 72 colored stones on a 12x8 board.
The stones are presented in a random order, and you can not look
ahead, i.e. you do not know what the next stone will be.
Object of the game is to place all 72 stones on the board.
Sounds easy? why don't you give it a try and find out for yourself
that this game is easy to learn, but addictive and hard!

Distribution is in binary form. You can order Xishido via our Web page:

http://www.fwi.uva.nl/~mdekker/ishido.html

We have binaries for the following platforms (list will become longer):

Linux
Solaris2.4
HP
DEC
SGI

Soon, SunOS and hopefully linux/68k will follow. If you want Xishido for
a platform not listed above, please do not hesitate and use the form
on our webpage to let us know what platform you use!

System requirements: it runs on any platform listed above, all you need is
a color display.

Xishido is shareware. If you order Xishido, you will be sent a copy of
the unregistered version. If you register by paying us the shareware
fee of US$20 (in cash), you will get the registered version, which
features a highscore list, 3 difficulty levels and sound.
Please note that the unregistered version is fully playable!

Please visit our webpage, it contains a full description of the game,
screenshots etc.
