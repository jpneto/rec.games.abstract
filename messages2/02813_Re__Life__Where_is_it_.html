Or, for X windows, there's X life. my copy is about five years old and the
user interface is a bit crufty, but it's really fast and allows enormous patterns
(the size is limited by your memory only). I looked with Lycos and found it
at "ftp://life.anu.edu.au/pub/complex_systems/alife/lie/xlife.tar".
Pretty neat that it was written so long ago, but it builds on my brand
new Linux system with just one change to a header file (there's a conflict
in the global namespace with a function named link).
