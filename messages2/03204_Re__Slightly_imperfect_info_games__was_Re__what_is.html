What about simultaneous movement games like Diplomacy. This uses
simultaneous movement. A similar game is R. Wayne Schmittberger's
Ozymandias, where players simultaneously order a number of armies and
then the weaker force is eliminated, the stronger force loses some
number of armies. An individual battle might turn into
rock/paper/scissors, but the vast majority do not.

What about AH's Football Strategy? (OK it's not abstract) but basically
one player on defense picks a card representing a defensive tactic, and
then the offensive player picks a play. The results are cross
referenced on chart to indicate a number of yards. (Example: Defense
run defense, Offense does long pass = long gain. But if Defense had
blitzed, the result would have been -10 loss on a sack, etc.) What
keeps the game from being a simple a random guess fest is that you must
account for current situation (downs, yards to go, clock management,
etc.)
