Announcing: tkAtaxx v1.0
(A strategy game similar to othello)

Requirements:

Tcl 7.4 and Tk 4.0 (or greater)

Features:

5 levels of computer opponent
Unlimited undo/redo
Game history window with Load and Save game
Layout mode - setup your own positions
Unplayable blocks for more variety and challenge

Read all about it, and download it from:
"http://www.cs.byu.edu/~williams/ataxx/tkataxx.html".
