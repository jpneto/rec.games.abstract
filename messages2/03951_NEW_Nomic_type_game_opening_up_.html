NEW nomic-like game opened:

The Fantasy Wargame Design Project is a collaboration effort by people to
create a Fantasy Wargame (hence, the title *s*). It uses a modified Imperial
Nomic ruleset to moderate the design process.

If you've never been involved in nomics before, this is how the project will
function: People (who have the game title of Imperial Senators) submit
proposals for new game rules or amendments to game rules. Votes are
collected and if the proposal passes (standard majority rules), then the
proposal goes in front of the Imperial Emporer (thats me *s*) who can either
accept or deny a proposal -- which in general, I'll accept proposals as long
as they fit within a set of broad guidelines to keep the project on course of
being a "Fantasy Wargame" system.

The game can flow in all sorts of different directions. Looking for game
players, designers, strategists, fiction writers, or those who just want to be
involved. Everyone is welcome!
