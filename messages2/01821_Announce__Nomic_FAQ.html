For those not in the know, Nomic is a game, unlike any other game I know.
Whereas most games obey some fixed set of rules, Nomic's rules are
changeable. In fact, the whole point of the game (at least initially)
is to change the rules of the game.

You start with an intial rule set which define some method of proposing
changes to the rules and putting them into effect, usually after a vote
among all players. If the vote succeeds, the rules are changes as proposed,
and play continues with the modified rule set in place.

Where it gets most interesting is when the rule which define how to change
the rules are themselves changed. Thus, although the game is initially
democratic, players could vote in rule changes which change the process
to resemeble capitalism, or communism, or monarchy, or gerontocracy or
whatever.

It is a lot of fun to explore the ways that government can change, and
to manipulate the balance of power. If you are interested, take a peek
at the FAQ - there are several games being played on the Net already,
and I'm sure they'd love to have new players. Or start a game of your
own. Typical initial rule sets are also available.
