There's a commercial version of "Psychological Jujitsu" for two or
more players, whose name I can't recall right now (!), but this has
both positive and negative reward cards. For a positive reward
the highest bid wins, but for a negative "reward" the lowest bid
takes it.

The way ties are handled in this game is to give the reward
to the _second highest_ bid (or if the reward is negative,
to the second lowest). If there is a tie for second place, then
the third highest gets it, and so on. Only if every position is
tied is the reward card discarded.
