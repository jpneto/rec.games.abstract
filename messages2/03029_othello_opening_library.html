I'm currently writing an Othello computer program and wish to include an
opening library in the code to improve its openings. I've noticed that
most programs these days tend to include that feature.

I've sorted out how to write transformation functions to convert the
4
possible "similar" positions according to the first black move (f5,e6,c3
or d4) and therefore can limit the library to only the standard openings
starting with f5.

But now I'm trying to figure out what the quickest and most efficient
method is of searching through the library to match the current moves
with the ones in the library.

I was thinking of creating a tree structure with the 3 first white moves at
the top (or 2 if I decide to eliminate the "parallel") with the following
black moves as children nodes and the following white moves as children and
so on...

Matching the opening would then just be a matter of traversing the tree
and if a move isnt found among the current nodes then the program should
exit "opening mode" and start thinking.

Can anyone tell me what they think of this method ? Maybe there are
drawbacks which I havent thought about.. Any advice from experience
Othello programmers would be appreciated.

Thanx
