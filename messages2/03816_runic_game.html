I have been for quite some time trying to design a game that uses tiles
(like Mah-Jong) as "runes". Each player is a wizard within some sort of

arena and each player has access to a number of these runes. Each rune
has a different power. I was thinking probably only four types of
runes, each being one of the four basic elements. Different
configurations of these rune stones would produce different effects.
Combining Air and Fire for example might produce a fireball. More
complicated configurations would produce bigger spells. Summoning a
fire elemental for example. The exact arrangment might be important.
Do you place this rune above another and place this one next to this
one. Things are becoming mightily complicated very quickly. I was told

that this place might be of some help. I'm using this to brainstorm and

shoot off some ideas. Can anybody help me?
