> In 1949, John Nash proved that in the game of Hex the first player has a

> But yes, the first player does have an advantage, which is why Twixt, like
> Hex, should always be played with the swap rule.

I don't see how a swap rule changes the fact that one side has a
certain winning strategy in Hex - it just shifts the advantage to the
2nd player.

Proof: Any position in Hex is (with perfect play) either a sure win
for the first player or a sure win for the 2nd player (since there can
be no draw and the game is non-random). Hence, every move that the
first player makes results either in a winning or a losing position.
A perfect 2nd player will know which is which and decide to swap if
and only if the position is a first-player win.

All the swap rule accomplishes (for a game with no draw) is to make an
obvious advantage for the first player into a less obvious advantage
for the 2nd player.

If the game has a possibility for draw, any position is either a
certain win, lose or draw (again, assuming no randomness and perfect
play). The best the first player can hope for with the swap rule is
forcing a draw, but that depends on the game: It may well be that the
first-move advantage is so great that no matter how bad the first move
is, the position is still winning. This would, like in hex, just move
the advantage to the 2nd player.

To get back to the original question about games that are better
suited for humans than computers, there are several factors that can
be exploited to effect this:

1) Make the search space large. Most computer programs for games
rely on (almost) exhaustive search of the next several moves. If
this is made unrealisable by having a huge number of possible (and
not obviously bad) moves, a human may exploit his cognitive
abilities to beat a computer. Go makes the search space large by
having a very large board with legal moves in every gridpoint.
You can also increase the search space by adding randomness or
hidden information (e.g. secret setup, as in Stratego).

2) Add more players. Interaction between three or more players is
hugely more complex than two-player interaction, so computers tend
to do badly at these, while such interaction is a natural part of
human life.

3) Add subjective elements. Apples to Apples is a prime example.

4) Add natural language understanding as an element. Ditto
