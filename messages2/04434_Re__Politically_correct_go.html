I was thinking about small variants, like 3x3 version of this (can I
call the game Neto-squares? :-)

It looks like 3x3 would be a 0-0 draw with perfect play. Either player
only has to avoid letting the other side make the 3x3 square and capturing
the middle stone. Remove it and the edge stones first, and a draw ensues.

Joo Neto wrote in an earlier message:
>>>Another ideia is to start with the 19x19 board full of grey stones.
>>>Then, alternating moves, each player removes a stone (that stone is
>>>not captured)

If we modify this to so that when making the smallest possible capture:

x x x x
x - - x
x - + x
x x x x

like the above, the capturing player gets to keep one stone for
completing the square. This should avoid any 0-0 draws and perhaps make
the game more interesting on larger boards too. Likewise, for large
captures include one stone for completing the square(s).

Maybe it would still be drawish after that, but at least not with 0-0
scores.
