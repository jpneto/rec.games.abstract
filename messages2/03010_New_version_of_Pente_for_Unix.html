I've just finished up a new version of Pente for Unix and X11. Changes
over older versions:
- Much more portable (now known to compile and run with no problems
on Linux, Solaris, SunOS 4.1.3, DYNIX/ptx, and HP-UX).
- Bilingual! Now can operate in French too, thanks to Eric Dupas.
Anyway, if you had the old version, or are interested in Pente, Renju, or
other games of five in a row, you might want to check it out. You can
download the source code or a Linux binary from
"http://www.hevanet.com/wms/pente.html".
I hope you like it!
