Complexity of Virtual Connections in Hex

Hello,

as a part of my studies at Stuttgart University (Germany) I could show
that the set of virtual connections in the Game of Hex is
PSPACE-complete.

By "the set of virtual connections" I mean the virtual connections that
can be built up by Anshelevich's AND/OR-deduction rules starting from
the basic ones, the pairs of neighboring cells.

A conclusion is that an exhaustive search for virtual connections in a
concrete game situation is (in general) not feasible in polynomial time.
This explains theoretically the necessity of heuristics in Hex playing
programs that search for virtual connections (like Hexy or Six).

Note that this result is not an easy consequence of Reisch's result (the
set of winning Hex games is PSPACE-complete), because the deduction
rules are incomplete. Nevertheless I could use Reisch's PSPACE-hardness
construction for my result.
