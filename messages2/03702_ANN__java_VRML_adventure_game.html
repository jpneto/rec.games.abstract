Check out:

http://vrml.sgi.com

"The Terrible Samaritan", a first of its kind use of VRML 2.0's java
external authoring interface, created by Cicada Interactive and
sponsored/distributed by Silicon Graphics' new Cosmo Software division,
just went live.

It's a 3D adventure game which uses an (optionally) installable java
client to create a seamless infinite universe of mountains, deserts,
rivers, and dozens of interactive realistically animated characters.
It's backed by a database server which allows you SAVE & RELOAD games,
and a multi-user server that allows you to make permanent changes to the
world from any web-browser and chat with other players.

Everything's free, naturally -- it's advertising sponsored.
