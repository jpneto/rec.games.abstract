AAAARGGHH! It's actually worse than it looks, because one must *first*
solve the simpler problem, of what to do, and what the value is, for
even a single half-open four!

e.g. . O X X X X . .

Either can try to play at the end (E) or elsewhere on the board (B).

Then we get O
E B
---------------
| | | where v is the value of the game
E | v | 1 | after both make a move elsewhere,
| | | (which is probably, but I'm not sure
X |-------+-------| definitely, the same as the value
| | | we're trying to calculate here)
B | m | v |
| | | and m is the value of the game
--------------- after a free move by X and the
open 4 closed off.

Even assuming you can get an estimate for m, and thus solve for v,
[ v = (v^2 - m)/(2v - m - 1) ], that still assumes the three v's are the same.

Nasty one!
