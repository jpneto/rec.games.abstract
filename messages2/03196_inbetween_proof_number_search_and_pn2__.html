I have implemented the pn2 search described in Allis'
work (1993 I think), and I wonder if any more research on
pn2 has been published.

In particular I wonder if the following might be an improvement:

instead of calling the second pn-search with a maximum of N
nodes, call it with N**q nodes, q small (or big) enough to fit
the entire search in memory [nb. N**0.5 means sqrt(N)], in the
hope that less search is waisted on second pn searches which
result in 'unproven'.

I have done some tests myself, but they are inconclusive.

For those thinking 'what the hell is pn-search', there is a reference
on my www page.
