I've written a Loose script for the Zillions of games program. It's available for download in the Zillions pages:

http://www.zillions-of-games.com/cgi-bin/zilligames/submissions.cgi?do=show;id=2006

It features all odd-sized boards from 9x9 to 19x19. The AI is very weak, as in most games of this kind, so this is mainly intended to be used for human vs human play.
