That's not exactly what I want to measure -- it's not the limit on the
winnings or average winnings I'm interested in, it's a limit on a
_probability of the distribution_. I suspect there are many sequences
with no limit on the average, but with a limit on P( X >= 0 ) -- an example
is a sequence of random i.i.d. X_i's where each follows the distribution:

P( X=1 ) = 0.8
P( X=-1 ) = 0.1
P( X=2^x, x > 1 ) = 1/( 20 * 2^x )
P( X=-2^x, x > 1 ) = 1/( 20 * 2^x )

The mean and variance of X_i are undefined, but P( X >= 0 ) is certainly
defined (0.85). What I want is the limit on P( sigma X >= 0 ) as n tends to
infinity. P( sigma X >= 0, n = 1 ) is 0.85 as above; P( sigma X >= 0, n = 2 )
is a bit harder but by enumerating each possibility I get P=0.895. I suspect
but cannot prove that the limit is 1, and so the strategy that wins this
distribution dominates the other. (If I could show that it dominated every
other possible strategy, it would be Wong-optimal.) In any case, the sequence
is monotonically increasing, because P( sigma to n+1 > 0 | sigma to n > 0 ) >=
P( X_i > 0 ) -- if you started off ahead before we played this game, you are
more likely to be ahead after this game than if we started off even. I
guess it's vaguely like a martingale except it relates to the probability,
not the sum. Since the sequence is monotonically increasing, the initial
term is 0.85, I can claim that any value is bounded by 0.85 <= sigma to n <= 1
for arbitrarily large n -- which satisfies the Wong-domination requirement of
P >= 0.5 for sufficiently large n.

The reason all this is relevant of course is that probability distribution
above is one that applies to simple strategies in backgammon-like troublesome
games: if we both play a backgammon-like game, and our strategies are "never
double except in a troublesome position; in a troublesome position then
always double and always take; otherwise, select chequer play such that
Ullrich wins non-troublesome games with probability 8/9" and troublesome
positions arise with probability 1/10, then X (the amount won by Ullrich in
a single game) is exactly as described above: P( X=1 ) = 0.8 is Ullrich winning
8/9ths of the 90% of games that never reach troublesome positions; P( X =-1 )
is Wong winning the remainder of the non-troublesome games, and the St.
Petersburg-ish other two probabilities are our (even) chances of winning
various amounts in troublesome games.

With a bit of hand-waving (add laws of large numbers and limit theorems; mix
well and heat) I believe the two optimalities are true for independent
variables and finite means and variances, because for large n then the
mean is almost surely non-negative. This is sufficient for Ullrich-optimality;
it also implies Wong-optimality because the sum tends to a distribution
(ie. normal) such that P( X >= mu ) >= 0.5; and since mu >= 0 we have
P( X >= 0 ) >= 0.5 and hence Wong-optimality. Without independence or
finite means and variances, then the result does not necessarily hold.
