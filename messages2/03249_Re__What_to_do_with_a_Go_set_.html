Just to throw in another two cents' worth, I'd also recommend "The Many
Faces of Go"--a computer program by David Fotland. I bought a Go set in
1975 but never learned the game until about three years ago, when I
installed TMFG on my PC. Now I have a ready & willing opponent all the
time. TMFG is a great way to learn the game, because although it's
simple, Go does take a lot of getting used to.
Btw, I also thought it'd be kinda neat to own a game-set that can be
used for many games. For a long while I toyed with the idea of using a
mah-jongg set for that purpose. If you're willing to draw or buy boards
for some games, you can use a mah-jongg set for chess, checkers, shogi,
chinese chess, nine men's morris, Stratego, and many other games. I
haven't done it--but it still seems like a neat idea. :)
