I have also done some design work towards a game that uses a mapboard
composed out of smaller pieces. This is in itself not a new idea,
several games have done this to some extent:

- Magic Realm uses Hexagonal pieces with roads/paths to create a map
with weird connectivity.

- Kings & Things and Die Siedler uses hexagonal pieces to make a more
traditional board.

- Wizards (Avalon Hill) uses fairly large hexagonal pieces each with
smaller hexagons to build a map.

- Magic Wood and Sorcerers Cave use rectangular cards to produce a
map of paths.

My idea sounds similar to yours, with terrain borders at the edges of
the pieces, but it uses rectangular tiles to produce a hexgrid map.

Each tile contains a central hexagon and 6 semi-hexagons. The tile
are laid out in a staggered pattern with matching connections like
this:

The letters represent terrain: S = sea, P = plains, F = forest and M =
mountain. These are better represented by colour, but the ASCII format
doesn't allow this. I have omitted some hex-borders to allow areas
that are more than one hexagon in size (missing borders are most
likely in sea, then plains, then forest and finally mountain). For
more universal use, these could be made dotted and count as borders in
some games. The asterisks in some hexes represent resources, and can
have different uses depending on the game played. If the height/width
ratio of the tiles is 2/sqrt(3) the hexagons are regular, but the
standard trading card size will not be too bad.

An area is counted as part of the board if it either contains the
middle of a tile or extends across two or more tiles.

You can add more terrain types (e.g. swamp) if you like, but that will
increase the number of tiles you need to have to avoid having to
backtrack too much when building a map (otherwise, it can get to be
like those puzzles where you have to match heads with tails). You can
also add rivers (which cross tiles at restricted places) but that
gives the same problem.

It has been suggested in the "death of wargames" thread that a problem
with wargames and similar board games is that once you have bought it,
the publisher doesn't get more from you for that game. In contrast to
this is role-playing games where you buy adventures and sourcebooks,
trading card games where you buy ever more cards and GW games where
you buy miniatures.

A game based on such tiles as the above can generate add-on sales by
publishing additional tiles (the number of different tiles is
staggering enough to make this never-ending) or additional games using
the same tiles. This will decrease production cost too, requiring only
game tokens and rulebooks for the additional games. Additional terrain
types could be introduced by expansion sets with tiles using that
terrain and rules describing how to use the terrain with the various
published games.

I now place this idea in the public domain, allowing anyone interested
to use it commercially or privately. If someone does use it
commercially, I wouldn't mind free copies of the games, though. ;-)

As for using these tiles for existing games, here are a few
suggestions:

Civilization: The number of resource asterisks determines the
population an area can support: 1+#asterisks. Forest count as
floodable areas (for the flood disaster). Volcano tokens are
distributed randomly among the mountain areas. Starting ares for each
nation are chosen randomly at the start (before players choose
nations) by selecting a tile. Any area (even partly) on that tile is a
legal starting area for this nation. Use the same AST track for all
nations but use the standard (reverse) AST order to determine order of
play.

Britannia: Mountains count as hilands, forest and plains are
identical. Assume that the tiles are surrounded by sea with each sea
area neighbouring two tiles. The sea area will include any sea area
bordering the edges of the tile (this may make a sea area on a tile
part of two sea areas. Choose one). Nations starting on the board each
get an army in a random land location. Then additional armies are
distributed in the following way: Starting with the area directly
north of the starting area of each nation, add an army if the ares is
an empty land area (and there are available armies). Then (again for
each nation) go clockwise round the starting area, adding armies if
the area is empty. When all the ares surrounding the starting area
have been checked, go round the circle at distance 2 from the starting
area etc. Note that the armies may be disconnected and that not all
nations get the same number of armies. For each nation not on the
board at the start of the game, choose randomly a sea area at the edge
of the board and let that nation start there. Since the potential
income of a nation is now very much different than in the standard
game, auction off the nations to the players after the initial set
up. The points used to purchase nations are subtracted from the
victory points afterwards. Nations enter the game at the standard rate
and count VP as usual for killing other pieces, but whenever VP for
areas are mentioned all areas count the same victory points for all
players: 1 plus one half times the number of asterisks. This includes
limes points for the Romans. The special Welsch VP for holding York
are dropped.

In both Civilization and Britannia the omitted (dotted) borders do
not count, so areas may be more than one hex.

I haven't played any of the other games mentioned at the top, so I
don't have any suggestions for these.
