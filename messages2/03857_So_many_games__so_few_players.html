So many games, so few players

From: ddyer@netcom.com (Dave Dyer)
Date: 26 03 1998 00:00:00 GMT



There must be hundreds of interesting games that can be played somewhere
on the web,
but the game rooms for them are mostly empty; sadly a self-reinforcing state.

What to do? Perhaps form a gang (er - CLUB) to attack a new game every
now and then.

The key idea is to create a critical mass of players so the chosen game
can be played
and evaluated for a while - because a game with no plauyers is no fun.

The basic outline: Get a collection of a hundred or more players.
Select a relatively
unknown but worthy game that can be played free online. Play it, discuss
strategy,
organize an informal tournament or two, maybe build a web page about the
game. Then
move on to a new game.

If you would be interested in participating, drop me a line with your
suggestion(s)
for what game should be the first victim.
