>> That's an interesting statement. It's one I immediately rejected
>> on the grounds that chess is a constructive system. Legal positions
>> are ones that can be generated from the axioms via the inference
>> rules. But, I suppose the problem I'm having is.... what is
>> the negation of a chess theorem? See... I would interpret Godel
>> application to chess as: There are some positions P for which
>> both P and not P can be reached OR there are some positions P
>> for which neither P or not P can be reached.
>
>Well, it seems that there is a fundamental error here: it is assumed that chess
>is a formal system under which 'not' exists.
>
>A formal system need not have clearly defined notions of not (let alone other
>mathematical entities, like integers, rational numbers, etc...); I would point
>you as an instance to the MIU system in Godel, Escher, Bach. Normally, a
>formal system is associated with a model (ergo, a set of axioms about number
>theory associated with the familiar facts about nonnegative integers), but it
>need not be in order to be a formal system. Chess is not a model of any
>familiar (other) mathematical entity I can think of (aside from possibly a
>medieval war, very loosely modelled); it's just chess.
>
>Can you see what I mean about a formal system without an interpretation?
>
>(Note: in such a system, it may well be impossible to define contradiction.)

I imagine it would be pretty hard to define "contradiction" in *any*
system that does not purport to model "truth" in some way.

However there may be some loose analogies to "not" in chess, not to
be used to define contradiction nor to help in the attempt to use
Godel's results, but just for curiosity/fun:
1) switch the board positions of the two kings;
2) switch the colors of all the pieces.

Have fun.
