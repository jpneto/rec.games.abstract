Yep. Maybe you could also auto-shoot if an enemy lined up along a
mirrored path, but you'd still need protection against getting trapped
by piled up objects. It might be a nice feature to have an auto-shoot
mode that you could toggle into and out of, though. You can guard a
row or column with it on and an enemy tank can't step onto it and turn
around to shoot you, no matter how quick he is. He would be toast as
soon as he stepped in-line.

>Another thought I had about the game is that eventually, all the mirrors
>and guns will be pushed to one side of the map. Think about it - a gun
>facing left can never be pushed from the left. Thus, it will eventually get
>pushed all the way over to the left side of the screen. Mirrors are the
>same, except they can only be pushed in two directions. In addition, since
>objects like boxes in clumps cannot be moved, all the objects in the game
>will eventually be clumped together.

Well, this gives me another idea. If an object can't be pushed from
any side then it begins to degrade. When it fully degrades, it is
removed from the map. It takes two days for an object to degrade and
you can look at it and see how far away it is from disappearing. This
would also encourage the ongoing construction of forts because parts
of the forts would be constantly falling to pieces.

When an object disappears it reappears randomly somewhere else.

Hmm. I guess it could be a little bit complicated to tell if an
object is pushable or not. If an object has open space on two
opposite sides, call it "pushable".

Or maybe it should be that an object disappears if it hasn't been
moved for two days. Then the guns that get pushed all the way to the
left that are useless, but can still be moved up and down, will
reappear in a more useful location.

>Also, I'd like the ability to push things along without shooting. Just
>makes it easier when you want to move something from one area into another.

Definitely. If you are going to move hundreds of blocks around then
you need a more efficient interface. The tank could have a little
drone that detaches from it. You click on an object to move it, and
the drone quickly moves to the object. You pull the object to a
desired location and the drone quickly moves to an exposed side
opposite of the direction you want to move the object and pushes. You
move the object where you want it to be placed and release. The idea
is that the drone has no capabilities that the tank doesn't already
have--it just moves really fast and figures out how to move stuff for
you. It still has to find a path to the objects. If you try to move
something and it would be impossible to do it with the tank or needed
obstacles cleared first, then the drone wouldn't be able to move the
thing. Interface-wise you are just dragging objects around. I think
the drone could be just as fast as mouse movements.
