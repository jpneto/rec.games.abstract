Hello.

I have been trying for some time to find an efficient method
(a polynomial time one) to pave polyominoes with overlapping rectangles
- that is, with a minimal number of rectangles. I have come up with
a few interesting results, but the general solution is still eluding me:
even when the polyominoes haven't got any inner holes, the problem turns
out to be more difficult than I expected!

I would like to know whether anything has been published on that topic.
Paving polyominoes with some given polyominoes, like 3x1 rectangles,
is known to be NP-complete (with dominoes, there is an algorithm linear
in the size of the problem!).
I propose to use rectangles of any sizes instead,
which may overlap one another, while of course remaining whithin the
boundaries of the target polyomino (otherwise, one single rectangle would
always suffice).

Any clue? All references and suggestions are most welcome! I am interested
in all related problems - like the version involving non-overlapping
rectangles, which I haven't investigated so far.
